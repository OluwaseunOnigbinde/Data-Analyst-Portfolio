# FMCG Sales Performance Analysis
This project analyses FMCG sales performance using Power BI.

## Project Objectives
- Analyse sales revenue and profitability.
- Evaluate regional and product performance.
- Monitor sales representative performance.
- Identify monthly sales trends.

## Tools Used
- Microsoft Excel
- Power Query
- Power BI
- DAX
